# 截图占位

这里的图片是占位图（纯色块），请用你的真实截图替换，保持同名即可，README 会自动引用。

| 文件名 | 对应截图内容 |
| ------ | ------------ |
| `select-machine.png` | 启动后选择要管理的机器 |
| `manage-list.png` | 某台机器的映射列表 + 交互命令 |
| `install-frps.png` | 服务端 install-frps.sh 安装完成输出 |
| `install-frpc.png` | 客户端 install-frpc.sh 安装完成输出 |

建议宽度 800~1200px。
